# Irvine x86 Study Companion

An interactive study site for *Assembly Language for x86 Processors* (8th ed.) by Kip R. Irvine.

- Lessons for all 16 chapters, written as original study notes
- Interactive tools: number converter, registers, flags, stack, shifts, jumps, addressing, IEEE-754
- Cheat sheets and a self-check quiz for every chapter

**Open it:** https://rrpar.github.io/irvine-x86-study-companion/

Unofficial study aid; not affiliated with the author or publisher. Get the book for the full text.
